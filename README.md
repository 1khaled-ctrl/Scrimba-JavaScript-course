## About

This repo contains my progress and projects from Scrimba's **Learn JavaScript** course — a hands-on introduction to JavaScript fundamentals through 140+ interactive coding challenges.

## What I learned

- Variables (`let`, `const`) and data types
- The DOM — selecting and updating elements
- Strings, template literals, and string methods
- Arrays and array methods (`push`, `pop`, `shift`, `unshift`)
- Objects and object methods (`Object.keys`, `Object.values`, `Object.entries`)
- Functions, parameters, and arguments
- For loops and iteration
- Conditionals and truthy/falsy values
- Events and `addEventListener`
- `Math.random()` and generating random values
- JSON — `JSON.parse()` and `JSON.stringify()`
- `localStorage` — saving data that persists across page reloads
- Working with browser and Chrome Extension APIs

## Projects built

| Project | Description |
